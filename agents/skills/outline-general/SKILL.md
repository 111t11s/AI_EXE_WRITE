# 通用小说大纲设计技能

先遵守用户的类型、基调、篇幅、视角和已有设定。以下是构思方法，按本次任务的 JSON Schema 填写结果，不新增格式要求。

- 用一句话锁定“谁在什么处境下，为何要达成什么目标，凭什么行动，面临什么阻碍与代价”。把题材标签转换成可推进的故事承诺。
- 区分设定和剧情：地理、道具、能力只有改变人物选择或事件后果时才进入大纲。不要以设定百科代替故事。
- 从开局困境和预期结局倒推关键转折。每个节点说明起因、人物主动行动、阻力、结果及其如何触发下一节点，避免仅按时间罗列偶遇。
- 将长期目标拆成阶段目标，结合能力或事业积累与有动机的对手阻碍。阶段胜利可以带来新责任，无需为拉长篇幅反复拖延同一目标。
- 每卷明确目标、主要冲突、高潮的选择与代价、卷末状态及后续问题。让每卷至少解决一个具体问题；最终卷回应主线与人物成长，不另开替代结局的新坑。
- 主线、关系线、成长线通过同一事件互相影响。重要配角有自身目标和立场，人物变化需要经历支撑，不用标签替代行动。
- 反转先布置信息或行动线索。标明伏笔种下的位置、阶段用途与回收节点；胜利后留出后果、关系变化和情绪余韵，调整张弛。
- 交付前核对动机、时间、地理移动、能力边界、资源获得和前后状态。严格服从本次要求的卷数和篇幅，不从范文套用固定结构。

来源提炼：大纲模块设定、《小说大纲如何设定》、《大纲拓展》、《大纲详细写法》、商业写作新手指南及买断大纲模板中的创作字段。去除投稿个人信息、固定性别与人称限制、成功保证及机械字数比例。来源与重复关系见上一层 sources.json。

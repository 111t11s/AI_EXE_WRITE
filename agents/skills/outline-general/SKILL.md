# 通用小说大纲设计技能

先遵守用户的类型、基调、篇幅、视角和已有设定。以下是构思方法，按本次任务的 JSON Schema 填写结果，不新增格式要求。

## 选择合适的展开层级

- 只需要方向时，先写“谁在什么处境下，为何要达成什么目标，凭什么行动，面临什么阻碍与代价”，再给出开局、关键转折、高潮和结局。
- 需要从人物推演剧情时，按“人物约束与欲望 → 主动选择 → 事件与阻力 → 结果及新问题”展开；人物性格必须通过选择和代价体现，不能用标签代替行动。
- 需要可直接写作的计划时，再把每卷拆成剧情节点和章节小节。每个节点至少交代起因、行动、阻力、结果及对下一节点的影响；章节摘要写清场景、参与人物、冲突、信息变化和章末推动，不要只列事件名称。
- 交付层级随用户要求调整，不把模板中的固定章节数、固定小节数或机械字数比例当成规则。

## 先确定本卷主题

- 生成每卷大纲前，先让用户选择本卷的主导主题；可提供发育/成长、逆袭、结尾收束、逃杀/生存、复仇、揭秘、关系推进或自定义主题。
- 主题是本卷的取舍标准，不是标签装饰。把它转成阶段目标、主要压力、关键选择、情绪落点和卷末状态；其他线索只能支持或反衬该主题。
- 用户没有选择时，先列出少量适合当前故事的选项并说明差异，再继续生成；不要擅自把所有主题平均混在一卷中。

## 从创意推进到可写大纲

- 采用“点 → 线 → 面”的扩展顺序：先用一句话确定创意点和核心承诺，再拉出主角目标、对手阻力和结局方向形成主线，最后展开分线、分卷、场景和章节。每次扩展都回答“谁在何处、想要什么、为何现在行动、受到什么阻碍、付出什么代价、结果改变了什么”。
- 新手流程可按以下顺序执行：立意与主题 → 背景边界 → 主角及关键人物 → 势力与资源 → 主线和辅线 → 分卷目标 → 关键节点 → 章节摘要 → 伏笔、状态和一致性检查。先保证因果链，再补充辞藻和细节。
- 五类基础材料可作为轻量清单：背景/地图、力量与规则、角色、势力、情节主线。只记录会影响选择、行动或后果的设定；地点按剧情需要细化，避免制作与主线无关的“废地图”。

## 组织故事材料

- 区分设定和剧情：背景、地理、能力、技能、道具、势力只有在改变人物选择、资源分配或事件后果时才进入大纲。八类材料可作为检查清单：故事背景、主要人物、世界设定、能力或技能、单章计划、总纲、特殊设定、待核实注解；缺少与故事无关的栏目不必硬填。
- 先明确书名暂名、主题承诺、内容简介、预计规模和环境边界，再安排人物、人物关系、主线与辅线。简介是故事承诺，不写成空泛的世界观介绍。
- 将长期目标拆成阶段目标，结合能力或事业积累与有动机的对手阻碍。阶段胜利可以带来新责任，无需为拉长篇幅反复拖延同一目标。
- 每卷明确目标、主要冲突、高潮中的选择与代价、卷末状态及后续问题。让每卷至少解决一个具体问题；最终卷回应主线与人物成长，不另开替代结局的新坑。
- 主线、关系线、成长线通过同一事件互相影响。重要配角有自身目标、资源和立场，关系变化要有可追溯的事件原因。
- 可用“九线”做漏项检查：主角线、配角线、能力/技能线、伙伴线、装备/资源线、冒险线、身世线、势力线、关系线。按题材取舍，不要求每部作品都完整具备九线；原本只适用于特定题材的后宫写法统一抽象为关系线。
- 开篇尽快让人物进入具体处境和核心冲突；优势或金手指应有来源、边界、代价和成长条件，避免无阻力地一步登天。每个分线、爽点和伏笔都要能说明它如何推动主线或改变人物。
- 反转先布置信息或行动线索。标明伏笔种下的位置、阶段用途和回收节点；记录未解决问题、后续注解和需要回填的设定，避免靠临场补丁解决矛盾。

## 校验与改写

- 从开局困境和预期结局倒推关键转折，避免仅按时间罗列偶遇。检查动机、时间、地理移动、能力边界、资源获得、人物关系和前后状态是否连续。
- 章节或分卷扩写时保留总纲的因果链；改写大纲时只改变用户要求的部分，并重新检查受影响的伏笔、人物状态、分卷目标和章节计划。
- 章节摘要以“行动推进”为核心，至少写明场景与参与者、行动、阻碍或冲突、结果/信息变化，以及章末对下一章的推动；画面、氛围和字数安排只能作为辅助。分卷结束时核对阶段目标是否完成、人物是否改变、代价是否兑现、遗留问题是否有计划。
- 改纲或采纳一致性修复意见前，允许用户编辑修复内容；采纳后只修复对应章节或受影响的上下游节点，并复查时间、地点、能力、资源、人物关系、伏笔回收和结尾状态，避免为了局部修补推翻无关情节。
- 模板中的范例人名、固定性别或人称、特定题材、投稿署名、协作流程和“百万字/固定小节”等内容仅是原文场景，不复制为通用要求。

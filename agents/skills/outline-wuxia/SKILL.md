# 武侠小说大纲设计技能

- 用主角的一次江湖选择开启故事：保护谁、追索什么、承担哪项承诺，如何卷入门派或地方势力的利益纠葛。侠义通过有损自身利益的选择表现。
- 武学成长与师承、天赋、练习、实战或奇遇相联系；每项收益要有获取过程、限制和后果。避免连续意外传功代替主角行动。
- 将恩怨拆成有不同视角的事实、误解、利益与责任。每次追查或交锋既推进目标，也改变主角对对手、师门或自身的认识。
- 江湖势力有生计、地盘、声望和内部立场。盟友与对手的转变由利益和选择触发，不能只依据正邪名称决定行为。
- 按既定尺度安排招式、内功、伤势、路程和情报。除非用户明确融合仙侠，不以突然飞升或无限境界替换武侠问题。
- 将卷末的武学变化与名望、恩义债、阵营和价值选择一起收束；最终冲突回答开篇承诺，胜负之外交代人物为选择付出的代价。

来源与适配：《大纲拓展》提供师承、天赋、奇遇及目标拆分方法；《武侠（仙侠）小说写作大纲详细指南》提供类型承诺、人物和情节互相推动的讨论，但大量篇幅为通用指南与神话范例。江湖生计、侠义代价等是据此整理的类型适配建议，不声称原文已有完整武侠模板。

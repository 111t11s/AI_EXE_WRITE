# 游戏与无限流小说大纲设计技能

- 先确定“游戏”是什么：系统、副本、虚拟世界、主神空间还是现实规则异变。写清进入条件、退出条件、重置规则和现实世界是否受影响。
- 规则必须可验证：资源、职业、技能、冷却、队伍人数、通关条件和失败惩罚。读者可以不知道全部规则，但关键时刻不能临时改规则救场。
- 每个副本或关卡要有独立目标、独特规则和可带出的代价。关卡不能只是换地图打怪；新规则应迫使人物改变策略、关系或自我认知。
- 设计资源经济：积分、装备、情报、治疗和复活如何获得、消耗和交易。让资源稀缺影响选择，避免主角无限刷取或系统凭空奖励。
- 系统或主神要有边界与逻辑。它可以发布任务，但不能无理由偏袒主角；奖励应来自完成条件、风险或隐藏信息，而非作者需要。
- 队伍关系是核心变量：信息是否共享、贡献如何分配、失败由谁承担、成员能否退出。队友不是技能挂件，反派玩家也可以有合理目标。
- 失败要有后果：死亡、永久损失、时间耗尽、现实牵连或队伍破裂。若设定可复活，必须写清代价和次数，不能用无限复活动摇紧张感。
- 无限流要控制节奏：每个副本解决一个完整问题，同时推进一条现实/身世/系统主线。不要用副本数量代替整体因果。
- 第一卷完成一个完整副本或游戏阶段，让主角理解规则、付出代价并作出一次关键选择。更高层规则和幕后势力只露必要一角。
- 避免大段系统面板和数值堆砌。用行动、失败和交易展示规则；数值只在影响判断时出现。

来源与适配：本条为游戏类型缺口补写，采用“入口规则—可验证机制—资源经济—失败代价—队伍关系—副本与主线”的通用方法；不绑定网游、无限流、无限恐怖或电竞中的单一子类型，具体系统与数值规则由用户设定决定。

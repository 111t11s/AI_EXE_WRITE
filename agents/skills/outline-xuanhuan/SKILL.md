# 玄幻小说大纲设计技能

- 将核心目标与修炼过程绑定：主角为何必须掌握某种能力、获得资源或进入某地？升级应解开一个行动条件，同时带来新的限制或责任。
- 先定力量来源、能力边界、突破条件与代价，再安排关键胜负。区分境界、实际战力、情报和协作；越级胜利须有准备和限制，避免临场追加免代价的能力。
- 用资源分布解释世界格局：谁控制修炼资源、为何能维持控制、其他势力如何应对。让地理、历史秘密和资源机制成为冲突的原因。
- 按主角行动需要展开地图。进入更大舞台前铺垫通道、信息、实力门槛与牵连；保留旧人物、旧势力与旧承诺的后果，不把换地图当作重启故事。
- 为势力写清目标、可调用资源、内部矛盾与结盟条件。主角可以通过交换、组织和制衡改变局势，不以强敌逐级出现代替全书因果。
- 分卷同步记录实力、资源、身份、关系及阵营格局的变化。让身世或世界秘密逐段揭示，并回到开篇承诺及最终目标。
- 金手指提供解决问题的方式，同时保留使用条件、代价和无法解决的事。持续升级要改变解题方式，不能只放大数字。

来源提炼：《玄幻大纲范文》的“力量—资源—地图—势力—目标—卷末状态”联动；《大纲拓展》的目标分解。范文只作结构案例，不复用其专有名词、九重境界、四卷、婚约或人物关系。

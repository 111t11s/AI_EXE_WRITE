# 灵异与怪谈小说大纲设计技能

- 先确定超自然存在的来源与规则：鬼魂、诅咒、仪式、地方神、规则怪谈还是未知现象；它如何出现、如何感知、什么会激怒或安抚它。
- 写清限制与代价：调查者能做什么、不能做什么，使用法术/仪式需要什么条件，失败会失去什么。不能靠临时新增能力或“主角特殊”直接破局。
- 恐惧来自未知、失控和代价，不只来自血腥。用环境、声音、身体反应、信息缺口和人物选择制造压力；jump scare 只能做短时刺激，不能替代持续悬念。
- 区分“怪谈规则”和“现实逻辑”。规则必须可被观察和验证，但不必一开始全部解释；每条规则至少有一次具体后果，不能只在设定里存在。
- 调查要有步骤：异常记录、求证、试探、误判、付代价、找到反制方式。让主角的行动改变危险，而不是等鬼自己出现。
- 地方民俗、信仰和历史创伤可以成为恐怖根源，但要区分传说、角色认知和已经发生的事实；不要用真实群体或现实宗教做未经核实的指控。
- 设计社会反应：目击者是否可信、机构如何掩盖或处理、社区如何自保。秘密可以保护人，也可以制造更大的伤害。
- 反派/超自然存在要有内在逻辑，不能只是“天生邪恶”。它的欲望、执念或规则与主角的选择发生冲突，才形成故事。
- 第一卷完成一个相对闭合的灵异事件，同时留下更深层的规则或幕后线索。不要把所有怪事都写成同一存在的预告。
- 结尾要回应恐惧的来源和人物付出的代价。驱魔、封印、逃离或共处都可以成立，但不能用一句咒语抹掉此前建立的所有损失。

来源与适配：本条为灵异类型缺口补写，采用“超自然规则—限制代价—恐惧层次—调查步骤—社会反应—事件收束”的通用方法；不绑定灵异、怪谈、恐怖、民俗或志怪中的单一风格，也不承诺真实民俗、宗教或法律解释。

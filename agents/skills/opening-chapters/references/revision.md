# 开局重写检查

以用户要求和原稿为边界，先找妨碍进入故事的实际问题，再决定修改范围。要求只改本章时交付本章完整正文，不顺带重写另两章。

- 关注分散：确认读者需先认清的人物、关系和目标；合并重复介绍或后置不影响当下行动的信息，保留群像计划中有作用的人物。
- 背景压住事件：把理解本次选择必须知道的规则留在前面，其余随使用、限制和后果透露。不能删掉让行动成立的因果。
- 悬念看不懂：补齐场景、目标和异常依据，留下答案；若读者只是缺少基本指代，继续隐瞒不会增加吸引力。
- 三章像三个开头：续接既有行动与后果，减少反复重置人物和背景；核对已露出的线索、持有物、伤势、知情范围与关系。
- 钩子没有进展：依据计划让问题增加新信息或获得阶段回应，不以更多谜团替代兑现，不提前揭露全书答案。
- 点题压过人物：把抽象评语还原到具体决定、动作和关系后果。确有作用的短句保留人物口吻，不为凑金句增加说教。
- 改动破坏后续：保持已经确定的线索顺序、身份、关键物件和承诺。资料不足时不假设后两章内容，更不伪造“前文已埋”的伏笔。

通读时检查段落、引号、错字、时间空间和事件完整性。只交付符合要求的正文，不附自查表、签约建议或“保证吸引读者”的结论。

# 都市小说大纲设计技能

- 先明确用户选择的是职场、创业、生活、情感还是都市异能。核心承诺落在具体城市生活和行业处境，职业本领要能改变主角的行动选项。
- 用“当前处境—立足机会—能力验证—关系形成—利益冲突—阶段结果”串起前期。机遇需要主角作出有代价的选择，不能靠连续中奖或权势救场完成成长。
- 事业线写出产品或服务、客户、资金、团队、竞争方式和关键瓶颈；时间跨度与增长规模匹配。财富和人脉来源可追踪，不能用一次投资解释所有成功。
- 让事业、家庭、友情和感情共享事件因果：合作产生信任，利益改变立场，选择影响关系。配角保留独立目标，不把所有异性简化成奖励。
- 若用户设定主角有特殊旧身份，用旧关系、未了责任或信息泄露将过去带回当下；不要默认退役特工、神秘组织、后宫或特权身份。
- 都市重生可用某个具体遗憾或未竟愿望建立行动动机，再限定记忆的时间范围、可靠程度和可兑现条件。主角改变一次事件后继续推演关系与机会的变化，不默认掌握全部未来、自动获利或必能挽回感情。
- 冲突升级先补证据和动机：从具体资源竞争到利益网络或历史问题，反派更换需有前因。反转揭示已有线索的新含义，避免无限追加幕后黑手。
- 按用户背景处理制度与能力边界；现实向故事用现实可成立的解决路径。都市异能需说明异常力量与城市秩序的关系，不在结尾突然改成修仙或宇宙征服。

来源辨析：《经典都市写作大纲二十二条主线》实际是一条连续套路链，编号也不完整，并非二十二种可独立套用的主线。仅提炼立足、事业与关系交叉、旧事回归和伏笔揭示；行业约束与人物自主性为本项目适配建议，未沿用原例的固定身份、性别刻板印象和突兀穿越结尾。

新人篇补充：《都市类小说类的创作要点》提供遗憾与愿望的行动入口、改变重生时间跨度的构思角度；记忆可靠度与变化后果为适配边界，不采用其读者群体刻板推断。

# 书名与简介

## 先明确同一个故事

把当前设定压缩为“谁处在什么局面，想要什么，受到什么阻碍，哪一点有别于相似故事”。从人物身份、目标、背景、关系冲突或核心疑问里选择最有辨识度的一项作为入口。没有确定的设定不为了一个好听的名字倒推出新故事。

书名、对外简介、章节标题与正文逐步展开同一承诺。名称暗示经营，正文却只有无关冒险，或简介承诺破案，开篇却始终没有相关事件，都应检查任务允许改哪一部分；不能直接推翻用户已有情节。已指定书名时沿用，除非用户要求改名。

## 书名选择

- 优先选便于理解、辨认、读出和记住的表达；简洁不是固定三至六字，文艺、长标题、数字和专有词都应按用户风格与故事需要判断。
- 类型信号来自实际内容。历史可突出时代与身份，经营可突出职业与困境，关系故事可突出双方的处境，幻想可突出关键规则与追求；这只是取名角度，不是必填关键词库。
- 将泛泛的宏大词换成与本书有关的对象或矛盾。检查名称是否只换一个角色就能用于许多别的故事；过于通用时寻找当前设定已有的独特联系。
- 悬念可以留出解释空间，但不虚构尺度、关系、类型或不存在的情节来吸引点击，也不模仿已有作品名称的字形与读音制造混淆。
- 用户要求候选时，提供有不同侧重点的候选，并简述各自对应的真实卖点；只需最终名称时直接交付，不强制输出比较表。

## 对外简介

简介让尚未读过正文的人看懂进入故事的理由。按需要组合背景中的关键约束、关注人物及其处境、具体愿望、触发变化的事件、阻碍和未决问题，不机械凑齐栏目。

- 用具体故事替代泛泛的人生感慨、世界历史和名词列表；一句话内出现过多专有名词时，只保留理解矛盾必需的部分。
- 在叙述或一小段有冲突的对白中显出人物的做法与文风。幽默、温暖、压抑或冷峻应与正文相符，不为了醒目硬加另一种语气。
- 保留会引导读者进入正文的问题，避免把全书所有转折逐一讲完。用户明确要剧透梗概、结局说明或大纲时则写清结果，不把“简介不剧透”扩大成隐瞒必要信息的规则。
- 第一人称和第三人称都可使用，先让“我”是谁、谁在说话清楚。句子长短服务表达，不强行禁用“我”或所有长句。
- 用短小的内容单元控制信息量；重要的是每句补充新的处境、行动或问题，不以“后面才精彩”“坚持读多少字”等请求替代吸引力。

原创微例：一座城的住址每天随潮位变化，负责送药的少女却只拿到昨日的地图。这个入口同时呈现规则、人物职责和眼前难题；若既有故事没有潮汐设定，不把此例当作可直接套用的剧情。

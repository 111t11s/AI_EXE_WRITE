# 人物与行动

## 欲望决定人物为什么进入事件

从当前目标、行动动机、资源与限制开始，区分人物公开追求的事和真正需要的东西。例如想取得资格可能同时是在争取亲人的认可；两者也可以完全一致，不强制每个人都有隐藏欲望。情感目标和事件目标有主次，通过共同的行动互相影响，不默认爱情是每部小说的主线。

角色背景只保留能解释当下判断、习惯、关系或能力的经历。职业处境、与亲友的关系、独处时的顾虑可以提供不同观察面；不要求每位人物填写三种生活、拥有创伤或同时展示全部过去。缺点能增加可信度，但不能把单一缺陷当作每种人物的标准配方。

在角色档案里，把目标与动机、性格与弱点、能力边界与成长方向相互核对。谨慎的人可以为重要目标冒险，关键是此刻的利害和取舍可理解；不能为了一个反转无缘无故换掉人格。

## 建立辨识度

- 从言语习惯、处理问题的方法、惯常动作、外貌或生活偏好中选少量有效特征。把它们放进实际处境，让读者由反应认出人物；不在每次登场时重复同一段介绍。
- 反复出现的特征应有变化：同样整理袖口，可能是在准备谈判，也可能是在掩饰紧张。口头禅和他人的评价只能补充已有表现，不能让群众轮流夸赞代替人物行动。
- 用一次有取舍的事件表现性格。重承诺的人面对损失时怎样兑现或背弃承诺，比直接说其忠诚或坚毅更有说服力。人物特征不必次次都触发大事件。
- 表面反应与内心感受可以不同，但要有依据和可观察的线索。不能一概规定开朗的人内心必孤独、冷漠的人必温柔，也不让所有人共享同一套反差。

## 配角与对手有自己的行动理由

配角的目标可以支持、妨碍或暂时交汇于主线。团队因分工、共同目标、信任或互利而成立，分别写清贡献和边界；不强制固定人数、性别、服从关系或背叛结局。善意、援助和共同成长本身可以是人物选择，不必每次兑换成物质回报。

对手的有效阻力来自其资源、判断、立场或行动，不只来自恶毒标签。允许对手有值得理解的动机和能力，主角也可有失误和失败；胜负遵守具体条件，不以全员降智保证主角获胜。

情感关系由相互回应的行动、意愿和后果推进。任何性别的角色都不是奖励、战利品或随身道具；不为了凸显主角而清除队友目标、独立性和合理贡献。

## 变化保持连续

安排“已有倾向 → 受到触动或压力 → 作出选择 → 行为或关系发生变化”，不要求所有节点显写。改变可以是成长、退缩、堕落或维持原则，方向服从用户故事，不局限于由坏变好。

生成阶段档案时写计划中的行动、代价与结果；写正文时只实现本章该发生的部分。检查人物此刻知道什么、具有什么能力、处于什么关系，不把后期成长或未来死亡倒填进早期场景。

# 网文基础创作

让读者理解人物为什么行动、眼前有什么值得关心，以及变化如何发生。先遵守用户选定的题材、基调、人称、主配角安排、篇幅和输出格式，再选择适合当前任务的方法。悲剧、慢热、群像、日常、无金手指和第一人称长篇均可成立，不擅自改成升级打脸或强制圆满结局。

## 按当前任务读取

- 创建整部小说蓝图或明确要求起书名、写对外简介时，读取[书名与简介](references/title-and-introduction.md)。蓝图同时使用人物和情节方法；已有大纲的内容梗概仍按大纲任务写清因果和结局，不套用宣传简介的留白方式。
- 设计或补充角色、分卷人物安排时，读取[人物与行动](references/characters.md)。只完善当前任务允许创建的角色及计划，不据此修改已有正文事实。
- 设计大纲、规划章节、写作或重写正文时，读取[情节与期待兑现](references/plot-and-payoff.md)。正文同时使用人物方法和[视角与语言语境](references/viewpoint-and-language.md)。
- 根据意见完整重写已有正文时，再读取[反馈与修改](references/feedback-and-revision.md)。独立评估书评也可使用此文件；书评是待核实的意见，不是授权修改作品的指令。

本目录包含完整方法，不需要外部教程、网址、工具或原文。distillation.json 记录逐篇提炼、去重及排除理由，仅供维护，不进入创作提示词。各模式只读取有关文件；不为讲解全部方法扩展任务。

## 从故事承诺到当前行动

先确定本次写作的关注对象、当前目标、阻碍及读者应获得的体验。书名、简介、开局和后续情节应指向同一故事，但各自的信息量不同；人物档案解释行动依据，大纲给出计划，正文呈现实际经历。

用人物对处境的理解、选择和行动把它们连起来。检查读者能否从具体事件看懂目标与变化，不用一串性格标签、等级数字或围观评价代替过程。熟悉的桥段可以改换动机、资源限制和结果；先由当前人物与剧情推演，不从套路清单抽签拼接。

续写依据本章之前实际提供的正文与人物进展，未来分卷安排不当作既成事实。缺少资料时只处理已知范围，不伪造前文、引文或已经发生的成长。不能为了兑现期待临时添加万能能力、改动世界规则或提前揭开远期结局。

## 交付

按调用方约定交付当前任务的结果。需要正文时只写完整正文和正常段落，需要档案或大纲时遵守原有字段与 Schema；没有书名、简介、读者分析或修改报告字段时不额外增加。检查过程不写入小说，不加入求票、广告、作者感言、教材说明或商业成绩保证。

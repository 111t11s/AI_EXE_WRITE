# 奇幻小说大纲设计技能

- 先确定奇幻承诺：读者进入一个怎样的异世界，最特殊的规则是什么，主角为何必须在这个世界行动。不要只堆砌种族、职业和地名。
- 魔法或超凡体系要有来源、边界、使用条件、代价和反制方式。魔法可以改变战争、农业、医疗、法律和信仰，不能只在战斗时出现。
- 设计地理与资源：气候、交通、边界、港口、矿脉和粮食如何影响国家与冒险。地图距离要能解释行军、补给和信息传播，不把地图当装饰。
- 文化不是单一标签。为不同群体写清生活方式、禁忌、权力结构、历史创伤与对外关系；避免把某个种族写成天然善恶或全员同质。
- 让魔法进入制度：谁有资格学习、谁被禁止、谁从中获利、违法使用如何处罚。学院、教会、行会和王室应有自己的利益，而不是同一条任务链上的布景。
- 主线可以是冒险、政治、成长或解谜，但主角必须有可执行的目标与选择。预言、天选和古神启示只能制造压力，不能替主角解决所有难题。
- 势力要写清资源、目标、内部矛盾和结盟条件。让政治变化来自利益和行动，而不是作者需要下一场大战。
- 第一卷先完成一个有限目标：离开故乡、取得一件关键资源、解决一处局部危机或揭开一层世界规则。跨大陆和神战留到条件成熟后再展开。
- 非人种族、语言、宗教和古代历史只写与当前行动有关的部分。避免用大量自造名词解释世界，让读者通过使用、冲突和后果理解设定。
- 卷末改变主角与世界的关系，并留下新的责任或未知；不要靠“摧毁一切”作为每卷默认高潮。

来源与适配：本条为奇幻类型缺口补写，采用“奇幻承诺—规则化魔法—地理资源—文化制度—有限冒险—卷末变化”的通用方法；不绑定西幻、东方奇幻、黑暗奇幻或童话奇幻中的单一风格，具体种族和魔法名称由用户设定决定。

# 末世与废土小说大纲设计技能

- 先确定灾难的原因、阶段和规则：病毒、气候、战争、异变还是未知事件；感染/污染如何传播、潜伏多久、能否治愈；世界是刚崩解还是已废土多年。
- 资源必须有真实约束：水、食物、燃料、药品、弹药、电力和安全住所。让获取、保存、分配和争夺资源成为剧情动力，不把物资当背景数字。
- 设计秩序变化：政府、军队、社区、帮派、宗教和家庭如何重组；法律、货币、贸易和暴力如何变化。末日不是所有人立刻变成野蛮人，也不是秩序毫无变化。
- 明确威胁规则：丧尸/怪物/环境何时出现、如何感知、如何反制、什么会吸引它们。关键战斗靠准备、地形、协作和代价，不靠临时觉醒。
- 主角要有可持续的生存能力，但不能无代价全能。伤病、疲劳、弹药、信任和道德选择都应限制行动；不要用无限物资或“天生免疫”解决所有问题。
- 让不同阵营有资源逻辑和内部矛盾。抢粮、封锁、隔离、牺牲少数人等选择要产生后果，不能只区分好人坏人和炮灰。
- 第一卷完成一个有限生存目标：逃出城市、建立临时据点、找到药品或护送某人。不要开局就解决灾难根源或统一所有幸存者。
- 写出希望与共同体的可能。末世可以黑暗，但若所有关系都只剩背叛，人物行动会失去意义；互助、规则和信任也可以是稀缺资源。
- 时间与地图要清楚：灾难第几天、季节、天气、道路和补给距离。迁徙和据点建设要消耗时间，不能一夜完成。
- 卷末改变安全边界、资源条件或人物对灾难的认知，并留下下一阶段必须面对的新问题。

来源与适配：本条为末世类型缺口补写，采用“灾难规则—资源约束—秩序重组—威胁反制—有限生存—希望与代价”的通用方法；不绑定丧尸、废土、天灾或异变中的单一设定，灾难规模和规则由用户设定决定。

# 悬疑与推理小说大纲设计技能

- 先确定核心谜题：谁做了什么、为什么、读者最终要回答什么问题。谜题必须有明确范围，不能靠“一切皆有可能”维持悬念。
- 建立线索账本：每条关键线索都要能指向或排除某种解释，并在正文中给读者看到。可以隐藏线索的含义，但不能只让侦探知道证据。
- 设计嫌疑矩阵：动机、手段、机会、关系和信息差。每个主要嫌疑人都要有独立利益与可核查的行动线，不能只当红鲱鱼。
- 区分“读者不知道”和“角色不知道”。视角控制、叙述顺序和误导必须公平；不可靠叙述可以成立，但不能用作者临时隐瞒关键事实代替推理。
- 让调查产生代价：时间压力、职业风险、关系破裂、二次伤害或新的犯罪。侦探不能零成本地反复盘问所有人。
- 反派要主动行动。销毁证据、转移视线、制造新事件或利用制度，都应改变调查条件，而不是等主角走到最后才交代。
- 安排揭示节奏：开局异常、第一次错误解释、关键证据、片面真相、中点反转、正面对抗、后果收束。每次揭示都应改变问题，而不是只增加信息量。
- 真相必须能回扣前文线索和人物动机。不能最后一章突然出现新凶手、新证据、双胞胎或梦境解释；如果使用叙述性诡计，须提前公平埋线。
- 第一卷可以完成一个相对闭合的案件，同时留下更大的未解问题；不要把所有案件都写成同一幕后黑手的连续预告。
- 关注受害者、社会关系与制度背景，避免把暴力当唯一刺激。悬疑的紧张来自信息差、选择和后果，不只来自血腥描写。

来源与适配：本条为悬疑类型缺口补写，采用“核心谜题—线索账本—嫌疑矩阵—调查代价—公平揭示”的通用方法；不绑定本格、社会派、刑侦、惊悚或犯罪中的单一子类型，也不承诺真实侦查程序或法律结论。

# 仙侠小说大纲设计技能

- 明确主角为何求道：长生、救人、自由、传承或其他用户目标。境界是行动条件，阶段目标要能说明主角为何此时冒险、舍弃或承担。
- 为修炼路径安排资源门槛、时间投入、能力变化和代价。寿元、伤势、心境或天劫仅在既定世界规则中采用，不把常见设定全部强加给作品。
- 宗门、家族、散修或仙界组织各有传承、资源与权力需求。把职位、信仰、地盘或修炼资源的分配转成具体人物冲突，避免罗列神仙名号。
- 人间与更高层世界的事件互为因果：先铺垫信息、进入条件和未了责任，再扩展舞台；飞升后仍需回应原有关系及承诺。
- 传承或法宝可以开启路线，也应限定用途、消耗与风险。重大突破由探索、选择与积累促成，不能临时借神祇身份取消全部困难。
- 若炼丹、炼器、阵法或符箓是本书关注点，让寻材、学习、尝试和制作中的取舍改变后续行动。所得之物有具体用途、成本与失败条件，不以稀有材料清单或反复寻宝代替过程，也不要求每本仙侠都安排制造副业。
- 将道心、承诺与人物变化写成关键行动。每卷交代修为、阵营、认识与未偿责任的变化，终局回应所求之道及其代价。
- 神话材料可用于构思组织关系和神人互动；区分传说与范文自创，不将源文中的虚构谱系当史实，不照搬专有角色和整段故事。

来源与适配：《武侠（仙侠）小说写作大纲详细指南》的神话范例展示神人关系、封授与势力重组；《大纲拓展》提供成长与目标拆分；《玄幻大纲范文》提供跨层世界的前因后果。修炼时间、求道选择等为面向仙侠的适配建议，卷数和境界名称由用户及当前设定决定。

新人篇补充：《仙侠类题材作品的创作要点及卖点》的亲手制作与长期、短期目标联系；制作成本与失败条件为适配建议，不把制造副业、天劫报应或某种市场偏好强制用于所有作品。

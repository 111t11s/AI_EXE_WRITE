# 言情小说大纲设计技能

- 先确定情感承诺：读者为什么要看这两个人走到一起，他们各自缺什么、怕什么、愿意为对方改变什么。不能只靠外貌、身份或偶然同居制造关系。
- 双方都要有独立目标、社会关系和行动能力。关系推进必须来自选择、回应和共同经历，不能靠一方持续越界、控制或拯救来制造“甜”。
- 设计内外两层阻力：外在可以是家族、阶层、职业、时代或距离；内在可以是价值观、创伤、责任或表达方式。冲突不能只靠一句误会拖十章。
- 关系阶段要可观察：相遇与吸引、试探与信息差、信任建立、价值观冲突、关系破裂或危机、修复与承诺。每个阶段都改变双方对彼此和自身的理解。
- 让情感线影响主线，也让主线改变情感线。工作、理想、家庭责任或历史局势不能只在恋爱间隙出现，否则两条线会互相悬空。
- 冲突升级要基于人物的选择与代价。分手、误会、牺牲和复合都要有前因后果；不要用绝症、车祸、失忆或第三者作为唯一推进器。
- 尊重同意和边界。强迫、监视、羞辱或权力不对等可以成为需要处理的问题，不能被包装成浪漫；具体尺度服从用户设定和平台规范。
- 配角要有自己的目的，不做只会助攻或破坏的工具人。朋友、家人、前任和对手都能提供不同视角，但不应替主角做关键决定。
- 第一卷完成一个关系阶段和一个外部目标：确认彼此的重要性、共同解决一处危机或作出一次不可逆选择。不要开卷就承诺一生一世。
- 结局要与全书的情感和价值选择一致。HE、BE、开放式结局都可以成立，但不能为了迎合甜或虐，违背人物已经建立的需求与边界。

来源与适配：本条为言情类型缺口补写，采用“情感承诺—双向主体—内外阻力—阶段变化—选择与代价”的通用方法；不绑定甜宠、虐恋、古言、现言或群像言情中的单一风格，也不把固定桥段当作类型规则。

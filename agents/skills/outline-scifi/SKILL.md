# 科幻小说大纲设计技能

- 先确定一个核心科学/技术变量：它改变了什么，不能改变什么，边界在哪里。软科幻也要有可自洽的规则，不把“未来科技”当作万能解法。
- 技术必须进入社会：谁掌握、谁维护、成本由谁承担、普通人如何使用、失败时谁受损。让技术改变劳动、战争、法律、阶层或信仰，而不只是换一套名词。
- 为技术写清使用条件、资源消耗、失败后果和反制方式。关键胜利应来自准备、信息、协作或代价，不在危机中临时发明无代价的新能力。
- 明确尺度：个人、城市、行星或星际。跨尺度前先解决交通、通信、补给、时间和信息延迟；不要让人物上午在首都、下午抵达边疆却毫无成本。
- 主角需要专业能力或可验证的行动位置，不能只负责听人讲解设定。用任务、故障、试验和误判展示规则，让读者在事件中理解世界。
- 对手和阵营要有资源与利益逻辑。企业、军方、殖民机构、AI 或外星文明都可以是力量，但不能只靠“邪恶”驱动；它们的限制同样要成立。
- AI、外星生命或异类意识要写清认知方式、交流条件和不可理解之处，不把它们简化成人类反派或全能工具。
- 第一卷优先完成一个局部目标：掌握一项技术、解决一次事故、验证一个假设或逃出一个系统。不要开卷就倾倒完整宇宙史和全部势力。
- 区分事实、推测和角色认知。科幻可以讨论现实科学，但不虚构可执行的危险操作、真实人物指控或未经证实的科学结论。
- 卷末改变技术条件、制度关系或主角对世界的理解，并留下下一卷必须承担的新问题。

来源与适配：本条为科幻类型缺口补写，采用“一个核心变量—技术代价—社会后果—尺度条件—局部验证”的通用科幻方法；不绑定硬科幻、太空歌剧、赛博朋克或蒸汽朋克中的任一子类型，具体科技名词由用户设定决定。

# 小说正文写作技能

把章节计划落实为人物正在经历的故事。优先遵守用户明确要求、原作风格、已提供的世界与人物事实，以及当前任务的输出约定；这些写作方法用于选择表达方式，不能据此更换题材、添加金手指、改变结局或扩展任务。

## 使用方式

- 初稿和重写均使用本文件、[场景技法](references/scene-craft.md)及[节奏与兑现](references/story-rhythm.md)。技法按本章实际场景取舍，不要求每章出现打斗、爱情、反转或所有描写类型。
- 重写正文时另外使用[重写与交付检查](references/revision.md)。局部一致性修复遵守原任务的最小改动范围，不套用整章风格重写。
- 本技能及其提示词均完整保存在本目录。无需外部教材、网址、原文摘录或写作工具。蒸馏取舍记录保存在本目录的 distillation.json，仅用于维护，不进入创作提示词。

## 先确定本章的边界

- 从已提供资料确认当前时间地点、视角、人物目标、冲突、前章停留的动作和本章应达到的结果。续章从该状态接续，不重复开篇介绍，不以整章回顾代替新行动。
- 大纲、章节摘要和分卷人物档案提供计划；已发生的事实以对应时期的正文与人物进展为准。不能把未来阶段的能力、关系、伤亡或结局提前写成现实；没有资料的既往事件不冒称前文已经发生。
- 只在既有规则内补足场景细节和合理的小动作。决定胜负的新能力、关键人物身份、重大资源、主线去向及结局不靠临时添加解决。人物优势必须沿用已知来源、限制和使用代价。
- 目标字数决定展开密度，不决定事件数量。优先写全本章关键行动与后果；不为凑字数重复争论、解释设定或加入支线，也不为赶字数跳过转折的依据。

## 把摘要变成场景

- 以“人物想达成什么 → 遇到什么阻力 → 如何选择与行动 → 结果改变什么”检查场景因果。冲突可以来自利益、认知、环境、责任或内心取舍，不限于争吵和暴力；温馨日常也可以通过一次决定或关系变化成立。
- 重要选择、信息揭示和情绪转折用具体场景呈现；重复劳动、无关路程和不改变局面的过程用简洁叙述过渡。叙述与描写各有用途，不把所有概述都扩成慢镜头。
- 回忆或补叙由当前事件触发，只补理解当下行动所需的信息，并明确返回原来的时间与场景；不在悬而未决的动作中插入无关长篇身世。
- 首章或新篇开局用一个可理解的小事件建立视角人物的处境、愿望、障碍和故事承诺。保留用户安排的群像、倒叙或慢热风格，不强制第一章打脸、出现金手指或凑足固定人数。
- 让行动、言语和细节共同承担人物塑造与信息传递；能让读者从选择看懂的性格，不再追加作者评语。每段优先保留会改变行动、理解、气氛或关系的信息。
- 环境规则在使用、交易、失败或后果中显现。例如资源紧缺应改变人物的取舍，而不只是增加一段世界说明。未知的专业事实不装作真实资料，不以资料不足为由离开本次写作去搜集工具或商业信息。

## 执行与交付

按章内因果写作，使用场景技法完成动作、对话与情感变化，再检查节奏、伏笔和前后状态。检查不作为正文的一部分输出。

交付完整正文及正常段落。服从调用方要求的格式，不添加创作过程、教材说明、技巧标签、自评、修改清单、重复章节标题或下一章的正文。人物进展数据由独立分析任务处理时，不夹带 character_updates。技能没有提供签约、流量或商业成功保证。

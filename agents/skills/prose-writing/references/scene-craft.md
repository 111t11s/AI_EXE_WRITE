# 场景技法

## 对话：让说话成为行动

- 写一段对话前明确双方各自想得到什么、知道什么、愿意透露什么，以及此刻的关系和情绪。台词须符合人物职业、经历、时代与语言习惯；不让所有角色共用作者的腔调。
- 让问答改变局面：试探、交换条件、拒绝、隐瞒、安慰、施压或作出承诺。潜台词来自真实的顾虑和利益，不要求句句拐弯；坦率人物和紧急指令可以直接说。
- 对方用词、停顿、回避或动作可显出言语与意图的差异。不要在每句台词之后解释“他其实想表达什么”，也不让不该知情的人准确说出隐藏真相。
- 精简现实闲谈中的客套、重复确认和已知信息。日常对白可以承担亲近、缓和、幽默或情绪恢复的作用，不能因没有争执就全部删掉；一段对话若信息和关系均未变化，再考虑压缩。
- 必要时在台词中间加入一个有意义的动作，让短句承受重点，或让动作提供与表面说法不同的线索。避免每句对白都配皱眉、冷笑、叹气、握拳等机械提示。
- 说话人清楚时可省提示语；多人加入、话题转向或连续几轮后重新标明发言者。人物换人说话通常另起一段，不能让省略说话人成为猜谜。

### 对话标点与动作句

前置提示语可写：她问：“船还开吗？”

后置提示语可写：“风停了。”他说。

同一句话被提示语分开时可写：“如果雨不停，”她说，“我们就在这里等。”

独立动作句可写：“等一下。”她把灯放到门边。“外面有人。”

依据句法选择冒号、逗号、句号、问号和叹号；完整动作句不机械套用“提示语在中间必用逗号”的口诀。维持人物语气，不把每段都改成同一种对话格式。

## 动作与环境：读者应能跟上发生了什么

- 用准确动词连接动作及其后果。人物拿起、交出、藏起或损坏的物件，须保持位置、持有者和状态连续；伤势、负重、体力、距离与先前行为会限制接下来的动作。
- 将动作与人物意图相连，同一举动在不同场合可代表试探、犹豫、掩饰或决断；不堆无目的的姿态，也不对每个动作附加心理解释。
- 在视角人物能感知的范围里选择环境细节。先让空间、人物与目标物的位置可理解，再沿注意力移动由远到近或从整体到关键局部，不随机切换观察位置。
- 视觉之外，可在确有作用时加入声音、触感、气味或味觉；例如噪声使对话受阻、寒冷使手指失灵。无需每段凑齐五感，也不把观景写成静态物品清单。
- 社会环境同样能形成阻力：门禁、规矩、价格、身份礼节、围观者的立场，都应落实到人物能做或不敢做的事情。

## 外貌：选择能被记住的特征

- 首次重要出场、处境明显变化或视角人物重新认识某人时，选少量有辨识度的外貌细节。衣物磨损、职业痕迹、惯常姿态可同时显出生活条件与性格，不必把五官和穿着逐项报完。
- 让细节随当下动作显现：奔跑改变呼吸和衣着，疲惫改变站姿，刻意整理服饰显出赴约的重视。不要每次出场重抄同一段肖像，也不把美丑直接判为道德或智力。
- 描写带有观察者的注意重点，但不能因此改写既定年龄、伤疤、衣着或身体状态。短暂路人只需能辨认，不与关键人物争夺篇幅。

## 心理：写出变化怎样导致选择

- 关键心理节点可用“刺激 → 人物如何理解 → 欲望与顾虑的冲突 → 选择 → 可见行动”落实。不是每步都要显写；重点是让决定有依据，而非突然宣布他愤怒、她感动。
- 按场景选用直接叙述、内心独白、动作与神态的侧面表现、环境与注意力的映照。无需每次都写“他想”，也不靠更换“寻思、盘算”等近义词掩盖重复。
- 直接叙述适合迅速交代清楚的判断；内心独白适合犹豫、自辩或认知转向；动作适合让人物有所保留；环境呼应应表现人物注意到了什么，不能凭天气替代人物感受。
- 维持既定叙事视角：有限视角不直接读取所有人的内心，不把表情判断当作客观真相；全知叙事的切换也须有组织。恐惧、误解、梦境和设想不是已经发生的事实。
- 高强度行动中的思考篇幅应与可用时间相称。保留真正改变策略的一念，不在挥刀途中插入整段人生总结。

## 打斗：策略、反馈与代价

- 只在本章需要打斗时使用。先确认争夺目标、冲突为何升级、双方已知能力、场地、距离、武器和限制；不强加擂台、裁判、围观群众或必须杀死对手的模板。
- 围绕“试探或进攻 → 应对 → 伤害、位置或信息的变化 → 策略调整”组织交锋。读者要能理解这一招为什么奏效、失败或迫使退让；招式名称和拟声词不能代替因果。
- 篇幅给改变胜负的攻防，略去机械重复。可用环境破坏、兵器受损、呼吸或疼痛反馈力量，不靠无限升级的形容词和群众反复惊叹。
- 双方会依据观察行动，配角不为衬托主角而失智。胜负来自已知条件下的选择、能力与代价；突发援手或新用法应有前提，不能凭空增加万能能力逆转。
- 战后写清本次目标是否实现，以及伤势、资源消耗、关系、责任或追索的变化。得胜不等于所有代价消失；败退、和解和脱身也是有效结果，服从原定剧情。

## 关系与亲密：落实到人物之间的变化

- 只在已安排的关系线需要时描写。用一次互相回应的行动、信任的交付、拒绝或边界协商表现变化，不因出现异性就自动制造爱情和多角关系。
- 亲密场景重在人物的意愿、情感和事后的关系影响；可在情绪落点处留白或转场，以后续相处体现变化。不要为凑篇幅添加露骨细节，也不把胁迫、拒绝或沉默自动改写为相互接受。
- 沿用用户选择的基调与人物关系，不强制甜宠、虐恋、性别分工或圆满结局，不复制教材中的人物和桥段。

# 墨间 · 小说工作台

大纲技能已从 `meterials/大纲相关` 蒸馏到 [agents/skills](agents/skills)。每个技能独立存放于 `agents/skills/<技能名>/SKILL.md`，包含 `name`、`description` 元数据和技能正文。选择小说类型后，问答页会显示已加载的技能；生成世界观蓝图及已有小说的新大纲时，后台根据当前类型读取技能正文。玄幻、都市、武侠、仙侠分别加载专项技能和通用技能，修真／修仙匹配仙侠；混合类型按出现顺序组合，科幻等暂无专项资料的类型使用通用技能。用户设定、篇幅、卷数及已有世界规则优先。

技能目录中的 `SKILL.md` 可直接维护，无需数据库迁移；部署时需包含 `agents/skills` 目录。资料校验值、去重关系及提炼取舍见 [来源清单](agents/skills/sources.json)。原始文档保持不变，运行时只加载提炼后的技能。接口 `GET /api/v1/novel-assistant/outline-skills?genre=玄幻` 可查询当前加载信息，需登录。

网页与 Android 打包：Linux 服务端见 [部署说明](deployment/README.md)，Android 见 [打包说明](mobile/README.md)。默认服务器为 http://49.232.132.111/，每个账号拥有独立书架。

从项目根目录启动现有 Python 环境中的应用：

```powershell
.\.venv\Scripts\python.exe -X utf8 main.py
```

本机打开 [http://127.0.0.1:8001/](http://127.0.0.1:8001/)（项目 `.env` 配置的端口）。如果改过端口，请打开终端里「工作台」后面的链接。页面由 FastAPI 一并提供，无需另启前端服务。项目读取与保存使用 `.env` 里的 MySQL 配置；生成与审读还需要当前 CrewAI 环境和可用的模型配置。

首次升级需执行账号迁移，详见 [账号与旧小说迁移](deployment/README.md#账号与旧小说迁移)。登录后只显示当前账号的小说；新建小说自动绑定登录账号。密码使用加盐 scrypt 哈希，登录状态可退出注销，默认有效期为 7 天。

登录后可在账号栏修改密码；忘记密码时由服务器管理员运行 `python -m db.reset_password 用户名`，交互输入新密码。修改或重置都会撤销该账号全部登录会话，详见 [密码重置说明](deployment/README.md#修改与重置密码)。

生成请求以后台任务运行，可继续使用书架，通过“任务中心 → 查看进度”打开实时思考与内容。任务中心包含“全部任务、世界观、大纲、正文、角色、章节规划、审读、一致性核对”等子菜单，每类显示生成中的任务数量。默认显示当前账号所有小说中正在生成的任务，可切换全部状态、已完成或未完成；每 4 秒自动刷新，全部状态下生成中的任务优先显示。关闭进度页或刷新浏览器后仍可回来查看，完成后可打开已保存结果。进度记录暂存于服务进程，服务重启会清除记录，数据库中已保存的小说内容保留。

从个人书架打开小说，查看当前世界观，然后：

1. 在「角色」点击「生成主角与重要配角」，根据当前世界观建立人物档案，可调整人数和补充要求。
2. 在「大纲与分卷」生成一个版本，选中一卷查看剧情节点，点击「生成本卷配角」；也可在「角色」选择大纲版本后点击「根据大纲补充配角」，再选择目标卷。第二卷起可勾选前卷配角安排新戏份；新增数量设为 0 可只复用旧配角。
3. 点击「规划章节」，选择起始章号和章节数。
4. 在「章节与正文」选中一章，生成初稿或手动编辑，再点击「审读本章」。生成前会检查角色信息；没有角色时会打开角色生成设置，由你选择数量并生成，完成后再写正文。审读建议不改动正文，刷新页面后不保留。
5. 在「一致性核对」选择对照大纲版本，跨页勾选需要阅读的章节，点击「核对所选章节」。任务在后台运行，通过「查看进度」查看实时内容及核对报告。

角色生成智能体通过 MCP 读取当前世界观、力量规则、势力及已有角色；补充配角时还读取所选大纲的分卷、剧情节点和前卷戏份。新人物保存到角色表，复用人物沿用原 ID，本卷新戏份单独保存到 `novel_volume_character`，并供章节规划和正文生成使用。在分卷详情可查看「本卷配角戏份」。已有数据库升级需执行 `python -m db.migrate_volume_characters`，新库直接导入最新版 SQL。同名、人数或复用 ID 校验失败时整批不保存；已有角色档案与前卷戏份不会被覆盖。旧角色简介明确写出前卷标题时，也可在后卷勾选复用。实时生成内容在任务的「查看进度」页面展示，完成后可直接打开角色档案。

一致性核对智能体仅在用户发起时读取所选章节的完整正文，结合所选大纲、人物档案、世界规则判断剧情、人物、设定及章节衔接是否偏移。每次 1–20 章，正文总计最多 120000 字符；无正文的章节不可选择。问题附章节原文、对照资料原文、偏移说明及修正建议，程序核验引文真实存在于本次读取资料。结论区分“未发现明确偏移”“发现偏移”和“资料不足”，不连续章号会注明范围限制，不对未读章节或全书作判断。核对不修改正文、人物和大纲；报告沿用后台任务的内存保留规则（服务重启或过期后清除），无需新增 SQL。

也可以点「新建小说」，通过问答生成并保存世界观。接口见 [Swagger](http://127.0.0.1:8001/docs)，MCP 接入见 [工具说明](agents/mcp/README.md)。如果端口已被占用，可在 PowerShell 先执行 `$env:PORT='8002'` 再启动，页面地址改用 `8002`。通过 `main.py` 启动时，内部 MCP 连接默认跟随该端口；如果已经配置了 `AITXT_API_BASE_URL`，请让它指向同一个 API。

# 墨间 · 小说工作台

网页与 Android 打包：Linux 服务端见 [部署说明](deployment/README.md)，Android 见 [打包说明](mobile/README.md)。默认服务器为 http://49.232.132.111/，每个账号拥有独立书架。

从项目根目录启动现有 Python 环境中的应用：

```powershell
.\.venv\Scripts\python.exe -X utf8 main.py
```

本机打开 [http://127.0.0.1:8001/](http://127.0.0.1:8001/)（项目 `.env` 配置的端口）。如果改过端口，请打开终端里「工作台」后面的链接。页面由 FastAPI 一并提供，无需另启前端服务。项目读取与保存使用 `.env` 里的 MySQL 配置；生成与审读还需要当前 CrewAI 环境和可用的模型配置。

首次升级需执行账号迁移，详见 [账号与旧小说迁移](deployment/README.md#账号与旧小说迁移)。登录后只显示当前账号的小说；新建小说自动绑定登录账号。密码使用加盐 scrypt 哈希，登录状态可退出注销，默认有效期为 7 天。

从个人书架打开小说，查看当前世界观，然后：

1. 在「大纲与分卷」生成一个版本，选中一卷查看剧情节点。
2. 点击「规划章节」，选择起始章号和章节数。
3. 在「章节与正文」选中一章，生成初稿或手动编辑，再点击「审读本章」。审读建议不改动正文，刷新页面后不保留。

也可以点「新建小说」，通过问答生成并保存世界观。接口见 [Swagger](http://127.0.0.1:8001/docs)，MCP 接入见 [工具说明](agents/mcp/README.md)。如果端口已被占用，可在 PowerShell 先执行 `$env:PORT='8002'` 再启动，页面地址改用 `8002`。通过 `main.py` 启动时，内部 MCP 连接默认跟随该端口；如果已经配置了 `AITXT_API_BASE_URL`，请让它指向同一个 API。

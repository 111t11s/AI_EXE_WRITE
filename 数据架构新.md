# AI 小说工程 — 数据库架构设计

> **版本**: v3.0  
> **数据库**: MySQL 8.0+  
> **字符集**: utf8mb4 / utf8mb4_unicode_ci  
> **引擎**: InnoDB  
> **设计原则**: 精简实用，10 张表覆盖完整 AI 写作流水线

---

## 一、表结构总览（10 张表）

| # | 表名 | 职责 | 类型 |
|---|------|------|------|
| 1 | `novel_book` | 书籍 + 写作进度（合并原 writing_progress） | 核心 |
| 2 | `novel_world` | 世界观设定 | 核心 |
| 3 | `novel_faction` | 势力/阵营 | 核心 |
| 4 | `novel_character` | 角色档案 + 动态状态（合并原 character_state） | 核心 |
| 5 | `novel_outline` | 大纲与剧情点 | 核心 |
| 6 | `novel_chapter` | 章节正文 | 核心 |
| 7 | `novel_story_memory` | AI 记忆层（合并原 chapter_fact + plot_snapshot） | AI 增强 |
| 8 | `novel_review` | 评审 + 一致性告警（合并原 consistency_alert） | 质量 |
| 9 | `novel_generation_task` | 异步任务调度 | 基础设施 |
| 10 | `novel_generation_log` | LLM 调用日志 | 基础设施 |

### v3.0 vs v2.0 变更

| 操作 | 表 | 原因 |
|------|----|------|
| **合并** → `novel_book` | ~~novel_writing_progress~~ | 进度字段（phase/最新章节号）放入 book 表，每书一条记录无需拆表 |
| **合并** → `novel_character` | ~~novel_character_state~~ | 角色当前状态用 `current_state` JSON 字段存，历史变更用 `state_history` JSON 数组存，消除双写 |
| **合并** → `novel_story_memory` | ~~novel_chapter_fact~~ + ~~novel_plot_snapshot~~ | 章节事实和剧情快照统一为"故事记忆"，用 `memory_type` 区分粒度 |
| **合并** → `novel_review` | ~~novel_consistency_alert~~ | 告警是评审的子类型，用 `review_type=7` 表示一致性告警 |
| **移除** | ~~novel_writing_style~~ | 风格规范是静态配置，更适合放 `skill/作家风格/` 文件目录，不需要建表 |

## 三、各表字段定义

### 1. novel_book — 书籍表

> 合并了原 `writing_progress` 的进度字段，每本书的所有状态信息集中在一行中。

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT UNSIGNED | AUTO_INCREMENT | 主键 |
| title | VARCHAR(200) | NOT NULL | 书名 |
| author | VARCHAR(100) | NULL | 作者名 |
| summary | TEXT | NULL | 小说简介 |
| genre | VARCHAR(50) | NULL | 题材（玄幻/科幻/都市/仙侠等） |
| writing_style | VARCHAR(50) | NULL | 写作风格名称（对应 skill/作家风格/ 目录下的规范文件） |
| status | TINYINT | 0 | 书籍状态: 0-筹备, 1-连载中, 2-已完结, 3-已烂尾 |
| **进度字段** | | | |
| current_phase | VARCHAR(30) | 'IDLE' | 当前写作阶段: IDLE / WORLD / FACTION / CHARACTER / OUTLINE / WRITING / REVIEW |
| last_chapter_number | INT UNSIGNED | 0 | 最后完成的章节号（冗余，与 chapter 表同步） |
| total_word_count | INT UNSIGNED | 0 | 全书总字数（冗余，定期汇总） |
| **时间戳** | | | |
| created_at | TIMESTAMP | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

```sql
CREATE TABLE novel_book (
    id                  BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY COMMENT '主键ID',
    title               VARCHAR(200) NOT NULL COMMENT '书名',
    author              VARCHAR(100)          COMMENT '作者名',
    summary             TEXT                  COMMENT '小说简介',
    genre               VARCHAR(50)           COMMENT '题材: 玄幻/科幻/都市/仙侠/历史/游戏等',
    writing_style       VARCHAR(50)           COMMENT '写作风格（对应 skill/作家风格/ 目录下的规范文件名）',
    status              TINYINT       NOT NULL DEFAULT 0 COMMENT '0-筹备, 1-连载, 2-完结, 3-烂尾',
    current_phase       VARCHAR(30)   NOT NULL DEFAULT 'IDLE' COMMENT '写作阶段: IDLE/WORLD/FACTION/CHARACTER/OUTLINE/WRITING/REVIEW',
    last_chapter_number INT UNSIGNED  NOT NULL DEFAULT 0 COMMENT '最后完成章节号（冗余字段）',
    total_word_count    INT UNSIGNED  NOT NULL DEFAULT 0 COMMENT '全书总字数（冗余字段）',
    created_at          TIMESTAMP     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at          TIMESTAMP     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='书籍表（含写作进度）';
```

### 2. novel_world — 世界观表

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT UNSIGNED | AUTO_INCREMENT | 主键 |
| book_id | BIGINT UNSIGNED | NOT NULL | 关联书籍 |
| summary | TEXT | NULL | 世界观简介 |
| detail | LONGTEXT | NULL | 世界观详情（力量体系/地理/历史/规则，JSON 或 Markdown） |
| status | TINYINT | 0 | 0-使用中, 1-已废弃 |
| created_at | TIMESTAMP | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

```sql
CREATE TABLE novel_world (
    id         BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY COMMENT '主键ID',
    book_id    BIGINT UNSIGNED NOT NULL COMMENT '关联书籍ID',
    summary    TEXT                   COMMENT '世界观简介',
    detail     LONGTEXT               COMMENT '世界观详情（力量体系/地理格局/历史沿革/核心规则）',
    status     TINYINT       NOT NULL DEFAULT 0 COMMENT '0-使用中, 1-已废弃',
    created_at TIMESTAMP     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at TIMESTAMP     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    FOREIGN KEY (book_id) REFERENCES novel_book(id) ON DELETE CASCADE,
    INDEX idx_book_status (book_id, status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='世界观表';
```

### 3. novel_faction — 势力表

> 去掉了 `tier`/`leader`/`territory` 等字段——这些都属于势力详情，应放在 `detail` JSON 中，保持表结构精简。

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT UNSIGNED | AUTO_INCREMENT | 主键 |
| book_id | BIGINT UNSIGNED | NOT NULL | 关联书籍 |
| name | VARCHAR(100) | NOT NULL | 势力名称 |
| summary | TEXT | NULL | 势力简介 |
| detail | LONGTEXT | NULL | 势力详情 JSON（含层级/领袖/领地/组织架构/外交关系等） |
| status | TINYINT | 0 | 0-活跃, 1-已覆灭, 2-已退场 |
| created_at | TIMESTAMP | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

```sql
CREATE TABLE novel_faction (
    id         BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY COMMENT '主键ID',
    book_id    BIGINT UNSIGNED NOT NULL COMMENT '关联书籍ID',
    name       VARCHAR(100)   NOT NULL COMMENT '势力名称',
    summary    TEXT                    COMMENT '势力简介',
    detail     LONGTEXT                COMMENT '势力详情JSON: {type, tier, leader, territory, organization, relations}',
    status     TINYINT        NOT NULL DEFAULT 0 COMMENT '0-活跃, 1-已覆灭, 2-已退场',
    created_at TIMESTAMP      NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at TIMESTAMP      NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    FOREIGN KEY (book_id) REFERENCES novel_book(id) ON DELETE CASCADE,
    UNIQUE KEY uk_book_name (book_id, name),
    INDEX idx_book_status (book_id, status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='势力表';
```

**detail JSON 结构示例**:

    "territory": "东域青云山脉",
    "organization": "宗主 → 长老会 → 内门 → 外门",
    "relations": {"林家": "同盟", "血魔宗": "敌对"},
    "core_techniques": ["青云剑诀", "天罡阵法"]

### 4. novel_character — 角色表

> 将原 `character_state` 合并至此。`current_state` 字段存角色**当前最新状态**（JSON），`state_history` 以数组形式记录每次变更（由 Agent 追加），不再需要独立的状态追踪表。

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT UNSIGNED | AUTO_INCREMENT | 主键 |
| book_id | BIGINT UNSIGNED | NOT NULL | 关联书籍 |
| faction_id | BIGINT UNSIGNED | NULL | 所属势力 |
| name | VARCHAR(100) | NOT NULL | 角色名 |
| role_type | TINYINT | 0 | 0-配角, 1-主角, 2-反派, 3-重要配角 |
| summary | TEXT | NULL | 角色简介（一句话定位） |
| detail | LONGTEXT | NULL | 角色档案 JSON（性格/背景/外貌/金手指/口头禅等） |
| current_state | JSON | NULL | **当前最新状态**（实力/装备/位置/心态，Agent 每章后更新） |
| state_history | JSON | NULL | 状态变更历史数组（每次变更记录追加到此数组） |
| first_appear_chapter | INT UNSIGNED | NULL | 首次出场章节号 |
| status | TINYINT | 0 | 0-活跃, 1-已退场, 2-已死亡 |
| created_at | TIMESTAMP | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

```sql
CREATE TABLE novel_character (
    id                   BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY COMMENT '主键ID',
    book_id              BIGINT UNSIGNED NOT NULL COMMENT '关联书籍ID',
    faction_id           BIGINT UNSIGNED          COMMENT '所属势力ID',
    name                 VARCHAR(100)   NOT NULL COMMENT '角色名',
    role_type            TINYINT        NOT NULL DEFAULT 0 COMMENT '0-配角, 1-主角, 2-反派, 3-重要配角',
    summary              TEXT                    COMMENT '角色简介',
    detail               LONGTEXT                COMMENT '角色档案JSON: {personality, background, appearance, golden_finger, catchphrase}',
    current_state        JSON                    COMMENT '当前状态JSON: {power_level, equipment, location, mental_state}',
    state_history        JSON                    COMMENT '状态变更历史: [{chapter, changes, timestamp}]',
    first_appear_chapter INT UNSIGNED            COMMENT '首次出场章节号',
    status               TINYINT        NOT NULL DEFAULT 0 COMMENT '0-活跃, 1-已退场, 2-已死亡',
    created_at           TIMESTAMP      NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at           TIMESTAMP      NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    FOREIGN KEY (book_id) REFERENCES novel_book(id) ON DELETE CASCADE,
    FOREIGN KEY (faction_id) REFERENCES novel_faction(id) ON DELETE SET NULL,
    INDEX idx_book_status (book_id, status),
    INDEX idx_book_role (book_id, role_type),
    INDEX idx_faction (faction_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='角色表（含动态状态追踪）';
```

**current_state JSON 结构**:

### 5. novel_outline — 大纲表

> 去掉了 `previous_outline_id` 自关联——通过 `sort_order` 即可确定大纲顺序，Agent 按序号查上一份即可。

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT UNSIGNED | AUTO_INCREMENT | 主键 |
| book_id | BIGINT UNSIGNED | NOT NULL | 关联书籍 |
| world_id | BIGINT UNSIGNED | NULL | 关联世界观 |
| title | VARCHAR(200) | NULL | 标题（如"第一卷·青石少年"） |
| summary | TEXT | NULL | 大纲简介 |
| detail | LONGTEXT | NULL | 大纲详情 JSON（剧情点列表/关键场景/伏笔等） |
| purpose | TINYINT | 1 | 0-开篇, 1-续写, 2-结尾 |
| characters_json | JSON | NULL | 出场人物 |
| sort_order | INT UNSIGNED | 0 | 排序序号（同书多卷按此排列） |
| status | TINYINT | 0 | 0-规划中, 1-执行中, 2-已完成, 3-已废弃 |
| created_at | TIMESTAMP | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

```sql
CREATE TABLE novel_outline (
    id              BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY COMMENT '主键ID',
    book_id         BIGINT UNSIGNED NOT NULL COMMENT '关联书籍ID',
    world_id        BIGINT UNSIGNED          COMMENT '关联世界观ID',
    title           VARCHAR(200)             COMMENT '大纲标题',
    summary         TEXT                     COMMENT '大纲简介',
    detail          LONGTEXT                 COMMENT '大纲详情JSON: {total_chapters, plot_points[], key_scenes[], foreshadowing, new_characters[]}',
    purpose         TINYINT        NOT NULL DEFAULT 1 COMMENT '0-开篇, 1-续写, 2-结尾',
    characters_json JSON                     COMMENT '出场人物: [{"character_id":1,"role":"主角","importance":"核心"}]',
    sort_order      INT UNSIGNED   NOT NULL DEFAULT 0 COMMENT '排序序号',
    status          TINYINT        NOT NULL DEFAULT 0 COMMENT '0-规划, 1-执行, 2-完成, 3-废弃',
    created_at      TIMESTAMP      NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at      TIMESTAMP      NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    FOREIGN KEY (book_id) REFERENCES novel_book(id) ON DELETE CASCADE,
    FOREIGN KEY (world_id) REFERENCES novel_world(id) ON DELETE SET NULL,
    INDEX idx_book_purpose (book_id, purpose),
    INDEX idx_book_sort (book_id, sort_order)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='大纲表';
```

### 7. novel_story_memory — 故事记忆表（AI 记忆层）

> **合并了原 `chapter_fact`（章节事实）和 `plot_snapshot`（剧情快照）**，统一为"故事记忆"概念。  
> - `memory_type = 'FACT'`: 章节级事实（战斗/突破/获宝/关系变化/伏笔等）  
> - `memory_type = 'SNAPSHOT'`: 阶段性剧情快照（每卷/每 N 章总结）  
> - Agent 生成新章节前，按 book_id + importance 降序查询记忆，获得"前情提要"

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT UNSIGNED | AUTO_INCREMENT | 主键 |
| book_id | BIGINT UNSIGNED | NOT NULL | 关联书籍 |
| chapter_number | INT UNSIGNED | NOT NULL | 关联章节号（快照时为截止章节号） |
| memory_type | VARCHAR(20) | NOT NULL | 'FACT' 或 'SNAPSHOT' |
| category | VARCHAR(30) | NULL | FACT 子类型: EVENT/RELATIONSHIP/ITEM/LOCATION/FORESHADOWING |
| content | TEXT | NOT NULL | 记忆内容 |
| importance | TINYINT | 1 | 重要度: 0-次要, 1-一般, 2-重要, 3-关键 |
| related_character_ids | JSON | NULL | 相关角色 ID 列表 |
| extra | JSON | NULL | 扩展数据（快照用: character_arcs, unresolved_threads 等） |
| created_at | TIMESTAMP | CURRENT_TIMESTAMP | 创建时间 |

```sql
CREATE TABLE novel_story_memory (
    id                      BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY COMMENT '主键ID',
    book_id                 BIGINT UNSIGNED NOT NULL COMMENT '关联书籍ID',
    chapter_number          INT UNSIGNED    NOT NULL COMMENT '关联章节号（快照=截止章节号）',
    memory_type             VARCHAR(20)     NOT NULL COMMENT 'FACT-章节事实, SNAPSHOT-阶段快照',
    category                VARCHAR(30)              COMMENT 'FACT子类型: EVENT/RELATIONSHIP/ITEM/LOCATION/FORESHADOWING',
    content                 TEXT            NOT NULL COMMENT '记忆内容',
    importance              TINYINT         NOT NULL DEFAULT 1 COMMENT '0-次要, 1-一般, 2-重要, 3-关键',
    related_character_ids   JSON                     COMMENT '相关角色ID列表: [1, 3, 5]',
    extra                   JSON                     COMMENT '扩展数据（快照用: {character_arcs, unresolved_threads, world_changes}）',
    created_at              TIMESTAMP       NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    FOREIGN KEY (book_id) REFERENCES novel_book(id) ON DELETE CASCADE,
    INDEX idx_book_type (book_id, memory_type),
    INDEX idx_book_chapter (book_id, chapter_number),
    INDEX idx_book_importance (book_id, importance DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='故事记忆表（AI记忆层: 章节事实 + 剧情快照）';
```

### 8. novel_review — 评审记录表

> 合并了原 `consistency_alert`——一致性告警作为 `review_type=7` 写入，用 `alert_severity` 字段区分严重程度。不再需要独立的告警表。

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| id | BIGINT UNSIGNED | AUTO_INCREMENT | 主键 |
| book_id | BIGINT UNSIGNED | NOT NULL | 关联书籍 |
| chapter_id | BIGINT UNSIGNED | NULL | 关联章节（整书评审/告警时为 NULL） |
| reviewer | VARCHAR(100) | NOT NULL | 评审员（Agent 名称或人工） |
| review_type | TINYINT | 0 | 评审类型（含告警，见下方枚举） |

## 五、AI 写作流水线数据流

```
① 建书 ─→ novel_book (设 writing_style 指定风格)

② 世界观 ─→ novel_world

③ 势力 ─→ novel_faction

④ 角色 ─→ novel_character (含 current_state 初始化)

⑤ 大纲 ─→ novel_outline
   └── 新角色入库 ─→ novel_character

⑥ 章节生成 ─→ novel_chapter
   ├── 提取记忆 ─→ novel_story_memory (FACT)
   ├── 更新角色状态 ─→ novel_character.current_state + state_history
   └── 更新进度 ─→ novel_book.last_chapter_number / current_phase

⑦ 阶段总结 ─→ novel_story_memory (SNAPSHOT)

⑧ 评审 ─→ novel_review (type 0-6)
   └── 发现硬伤 ─→ novel_review (type=7, alert_severity)

全程: novel_generation_task + novel_generation_log
```

    INDEX idx_book_created (book_id, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='生成日志表';
